# Sistema para Farmacias

Plugin WordPress para gestión de farmacias: productos, inventario por lotes, vencimientos, POS, clientes, ventas, Kardex y facturación electrónica mediante adaptadores por país.

## Estado

Proyecto en migración desde el prototipo validado `FarmaPOS Perú` hacia un producto genérico y multi-país.

- Producto comercial: **Sistema para Farmacias**
- Plataforma: WordPress
- Primera localización: **Perú**
- Arquitectura: core neutral + perfiles/adaptadores por país

La primera versión comercial conservará compatibilidad interna con los prefijos `farmapos_*` del prototipo mientras se desacopla progresivamente la lógica específica de Perú.
